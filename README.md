# SangRakshak — AI-Powered Women's Safety System

SangRakshak is an AI-driven security system designed to enhance safety for women by detecting potential threats in **real-time video feeds**. It supports **CCTV live streaming via RTSP/HTTP URLs** and **manual video uploads**, providing AI-powered analysis for **crowd detection**, **violence detection**, and **gender identification**.

---

## 🌟 Features

- **🎥 Multi-Frame AI Analysis** — Samples every 10th frame and feeds a 5-frame temporal sequence into the violence detection model for accurate, context-aware results.
- **📡 CCTV Live Streaming** — Monitors real-time CCTV feeds via `rtsp://` or `http://` URLs.
- **🔒 AES-256 Encrypted Processing** — Uses **Fernet (AES-256-CBC)** with a persisted key (`fernet.key`) for genuine at-rest and in-transit frame protection.
- **🚨 Correct Alert Logic** — Triggers an emergency alert only when a **female subject** is detected alongside **violence** or a **crowd** — using precise field comparisons, not fragile substring matching.
- **🧾 Structured Logging** — Every model load, inference call, and error is recorded via Python's `logging` module for auditability.
- **🎨 Responsive Gradio UI** — Clean two-column layout with separate panels for CCTV streams and video uploads.

## 🚀 Getting Started

### 1️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 2️⃣ Train the Models

Train the **Gender Classification** and **Violence Detection** models:

```bash
python training1.py
```

This downloads the datasets from Kaggle automatically via `kagglehub` and saves:
- `gender_classification.pth`
- `violence_detection.keras`

Train the **Crowd Detection** model:

```bash
python training2.py
```

This saves:
- `crowd_detection.keras`

> **Note:** A GPU is strongly recommended. Training on CPU will be very slow, especially for the ConvLSTM violence model. The scripts use `torch.device("cuda")` / TensorFlow GPU auto-detection automatically.

### 3️⃣ Run the Application

```bash
python app.py
```

Open the URL shown in the terminal (e.g. `http://127.0.0.1:7860`) in your browser.

## 🖱️ How to Use

### CCTV Live Stream Panel
1. Enter a valid CCTV stream URL (`rtsp://...` or `http://...`) in the **CCTV URL** field.
2. Click **Analyse Stream**.
3. Results appear in the **Stream Analysis** box.

### Upload Video Panel
1. Click **Upload Video File** and select a local video.
2. Click **Analyse Video**.
3. Results appear in the **Video Analysis** box.

### Output Format

```
Gender: Female
Violence: Violence Detected
Crowd: Crowd Present
Alert: 🚨 ALERT: Potential threat detected!
Frames analysed: 47 (sampled every 10 frames)
```

Alert is triggered **only** when `Gender = Female` **AND** (`Violence Detected` **OR** `Crowd Present`).

## ✨ Core AI Models

### 1. Gender Classification Model (`training1.py`)
- **Framework:** PyTorch
- **Architecture:** 3-layer CNN → 2 Fully Connected layers
- **Input:** `(B, 3, 128, 128)` — normalised RGB frames
- **Output:** Binary — `Male (0)` / `Female (1)`
- **Dataset:** [UTKFace (Kaggle)](https://www.kaggle.com/datasets/jangedoo/utkface-new)
- **Saved as:** `gender_classification.pth`

### 2. Violence Detection Model (`training1.py`)
- **Framework:** TensorFlow / Keras
- **Architecture:** ConvLSTM2D (64 filters) → BatchNorm → Dropout → ConvLSTM2D (32 filters) → Dense
- **Input:** `(B, 5, 224, 224, 3)` — 5-frame temporal sequence, normalised RGB
- **Output:** Binary — `No Violence (0)` / `Violence Detected (1)`
- **Dataset:** [Real-Life Violence Situations Dataset (Kaggle)](https://www.kaggle.com/datasets/mohamedmustafa/real-life-violence-situations-dataset)
- **Mixed Precision:** `float16` training, `float32` output layer
- **Saved as:** `violence_detection.keras`

### 3. Crowd Detection Model (`training2.py`)
- **Framework:** TensorFlow / Keras
- **Architecture:** 3 × Conv2D → MaxPooling → Dense (256) → Dropout → Dense (2)
- **Input:** `(B, 224, 224, 3)` — normalised RGB frame
- **Output:** Binary — `No Crowd (0)` / `Crowd Present (1)`
- **Dataset:** [CrowdHuman Crowd Detection (Kaggle)](https://www.kaggle.com/datasets/permanalwep/crowdhuman-crowd-detection)
- **Training features:** 80/20 stratified split, EarlyStopping, ReduceLROnPlateau
- **Saved as:** `crowd_detection.keras`

## 🔒 Security

All dependencies are pinned to CVE-patched minimum versions:

| Package | Minimum Version | Vulnerability Fixed |
|---|---|---|
| `torch` | `≥ 2.6.0` | RCE via `torch.load` (GHSA-53q9-r3pm-6pq6) |
| `gradio` | `≥ 6.7` | Path traversal on Windows + Python 3.13 (GHSA-39mp-8hj3-5c49) |
| `cryptography` | `≥ 46.0.5` | Weak ECDH/ECDSA key validation (GHSA-r6ph-v2qm-q3c2) |
| `scikit-learn` | `≥ 1.5.0` | Sensitive token leakage via `stop_words_` (GHSA-jw8x-6495-233v) |
| `Pillow` | `≥ 12.2.0` | Malicious PDF infinite loop / DoS (GHSA-r73j-pqj5-w3x7) |

> ⚠️ **Do not commit `fernet.key` to version control.** Add it to your `.gitignore`.

## 🧰 Key Implementation Decisions

| Issue | Fix Applied |
|---|---|
| Alert logic broken (substring match on list) | Replaced with exact dict-key comparison |
| Only first frame analysed | Samples every 10th frame; violence model receives 5-frame sequences |
| `torch.load` RCE vulnerability | Added `weights_only=True` |
| No frame normalisation | All frames normalised to `[0, 1]` with BGR→RGB conversion before inference |
| `frame_tensor` used before assignment | Each model builds its own tensor independently |
| All frames loaded into memory (OOM risk) | `SAMPLE_STRIDE = 10` prevents memory exhaustion on long videos |
| Crowd model trained on random dummy data | Retrained on real CrowdHuman dataset |
| Models saved in wrong format (`.pth` for Keras) | Keras models saved as `.keras`; PyTorch as `.pth` |
| Hardcoded Colab `/content/` path | Removed; `app.py` is a fully portable standalone script |
| No logging | Python `logging` module added throughout |
| Encryption key regenerated on every run | Key persisted to `fernet.key` for consistent at-rest protection |
